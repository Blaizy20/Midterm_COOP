PASSWORD RESET WITH PHPMAILER - SETUP GUIDE
=============================================

✅ WHAT HAS BEEN UPDATED:

1. Updated forgot_password.php to:
   - Accept EMAIL instead of username
   - Send password reset links via Gmail
   - Use password reset tokens (valid for 1 hour)
   - Two-step process:
     Step 1: User enters email → receives reset link
     Step 2: User clicks link and creates new password

2. Created migration file for database
   File: setup/migrate_password_reset.php

3. PHPMailer is already installed in vendor/ folder


📋 STEP-BY-STEP SETUP:

STEP 1: Prepare Gmail Account
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to https://myaccount.google.com/apppasswords
2. Select "Mail" and "Windows Computer"
3. Gmail will generate a 16-character APP PASSWORD (copy it)
4. You'll need your Gmail address too

STEP 2: Update Gmail Credentials in forgot_password.php
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Open: staff/forgot_password.php

Find these lines (around line 34-35):
        $mail->Username = 'your-email@gmail.com'; // CHANGE THIS
        $mail->Password = 'your-app-password'; // CHANGE THIS (Gmail App Password)

Replace with your actual Gmail credentials:
        $mail->Username = 'your-actual-email@gmail.com';
        $mail->Password = 'your-16-char-app-password';

Also find line 36:
        $mail->setFrom('your-email@gmail.com', 'Loan Management App'); // CHANGE THIS

Replace with:
        $mail->setFrom('your-actual-email@gmail.com', 'Loan Management App');


STEP 3: Run Database Migration
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Open your browser
2. Go to: http://localhost/LOAN_MANAGEMENT_APP/setup/migrate_password_reset.php
3. You should see "✓ Migration Successful!"

This adds two new columns to the users table:
   - reset_token (stores the reset link token)
   - reset_token_expiry (when token expires)


STEP 4: Test the Forgot Password Feature
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Go to: http://localhost/LOAN_MANAGEMENT_APP/staff/forgot_password.php
2. Enter your staff email address
3. Check your Gmail inbox for reset email
4. Click the reset link in the email
5. Create a new password
6. Login with new password


⚠️ IMPORTANT NOTES:

- Make sure staff accounts have EMAIL addresses in the users table
- Reset tokens expire after 1 hour
- Only STAFF can reset passwords (not CUSTOMER accounts)
- The email link must work from your network
- If testing locally, the reset link URL will use localhost


❓ TROUBLESHOOTING:

Problem: "Error sending email"
Solution: Check that Gmail credentials are correct in forgot_password.php

Problem: Email not received
Solution: Check Gmail spam folder or verify App Password is correct

Problem: "Invalid or expired reset token"
Solution: Click the reset link within 1 hour of receiving the email

Problem: "No staff account found with this email"
Solution: Make sure the user account has an email address in the users table
